About

I'm studying to become a Técnico en Computación at Escuela Técnica N.º 35 "Ing. Eduardo Latzina", Ciudad Autónoma de Buenos Aires. Most of what I know comes from building things, breaking things, and figuring out why.

I work mainly with GNU/Linux — Debian and derivatives — and have hands-on experience administering Linux systems and services on my own hardware, including Raspberry Pi servers. I'm interested in networks, systems programming, cybersecurity (especially binary analysis, web security, and reverse engineering), and electronics. I write firmware, prototype circuits, and have fabricated PCBs by hand.

I received hardware from Hack Club in recognition of my participation, including a Raspberry Pi 5 (16 GB).

Raffles Manager API

A REST API for managing raffle projects: raffle sets, numbers, buyers, and users. The system generates numbers automatically, tracks their state, and scopes all data per user. It was an exercise in backend design — relational modeling, authentication flow, and clean API structure.

Python · FastAPI · SQLAlchemy · MariaDB · JWT · Pydantic · bcrypt

LandSerM — LAN and Server Monitor

A modular event-management system for Linux servers and local networks. It detects defined events like service state changes — someday storage signals and SMART alerts — and executes automated responses. Built around systemd.

Python · Linux · systemd · Storage monitoring · SMART

SpanishDuckduino

Firmware for the Arduino Pro Micro that executes Duckyscript payloads with correct handling of Spanish (Spain and Latinoamerican) keyboard layouts. Most existing implementations ignore layout differences; this one accounts for them at the firmware level. I'm building an extension of this project with a remote payload selector and a WiFi bridge module to communicate with each other.

C · Arduino Pro Micro · ATmega32U4 · Firmware · HID · Keyboard layouts
